# MESIR Perfume — сайт с приёмом заявок через Telegram

Статический сайт (HTML/CSS/JS) с корзиной, избранным, фильтрами каталога,
переключателем языка (EN/RU) и формой «Отправить заявку» — вместо
настоящей онлайн-оплаты покупатель оставляет имя, Telegram и телефон,
а продавцу сразу приходит уведомление в Telegram с составом заказа.

## Структура проекта

```
index.html, about.html, contact.html   — страницы сайта
style.css, script.js, data.js, i18n.js — стили и логика
assets/                                 — логотип
api/order.js                            — серверная функция Vercel,
                                           отправляет заявку в Telegram
package.json                            — нужен, чтобы Vercel опознал проект
.env.example                            — какие переменные окружения нужны
```

## Настройка Telegram-бота (один раз, перед первым деплоем)

1. Открой в Telegram чат с **@BotFather**.
2. Отправь `/newbot`, придумай имя и username для бота (username должен
   заканчиваться на `bot`, например `mesir_orders_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — это и есть `TELEGRAM_BOT_TOKEN`.
4. Напиши **своему новому боту** любое сообщение (например «привет») —
   это обязательно, иначе бот не сможет писать тебе первым.
5. Узнай свой **chat_id**: самый простой способ — открыть в Telegram чат с
   **@userinfobot** и отправить ему `/start`. Он пришлёт твой числовой ID
   (например `123456789`) — это и есть `TELEGRAM_CHAT_ID`.

## Деплой на Vercel

1. Залей проект в GitHub-репозиторий (или используй `vercel` CLI — `vercel deploy`
   работает и без GitHub, отдельно от репозитория).
2. На [vercel.com](https://vercel.com) → **New Project** → выбери репозиторий.
3. Framework Preset — оставь **Other** (это не Next.js/React, просто статика + одна
   serverless-функция, Vercel поймёт сам).
4. **До первого деплоя** (или сразу после) зайди в
   **Project → Settings → Environment Variables** и добавь:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 3 выше
   - `TELEGRAM_CHAT_ID` — твой ID из шага 5 выше
5. Нажми Deploy. После деплоя протестируй: добавь товар в корзину →
   «Отправить заявку» → заполни форму → в Telegram от твоего бота должно
   прийти сообщение с составом заказа.

## Важно про бесплатный план Vercel

Hobby (бесплатный) план Vercel по их правилам предназначен только для
некоммерческого использования. Если сайт будет реально принимать заказы —
формально это уже коммерческое использование, и по правилам Vercel нужен
план **Pro** ($20/мес). Технически на Hobby всё будет работать без
ограничений — это вопрос соблюдения условий использования, а не
работоспособности кода.
