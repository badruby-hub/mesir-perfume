# MESIR Perfume — сайт с админкой и приёмом заявок через Telegram

Статический сайт (HTML/CSS/JS) с корзиной, избранным, фильтрами каталога,
переключателем языка (EN/RU), формой «Отправить заявку» вместо онлайн-оплаты
(заявка с контактами уходит продавцу в Telegram) и защищённой паролем
админ-панелью для управления товарами, hero-слайдами и текстами сайта —
без базы данных: все правки сохраняются коммитом прямо в этот репозиторий,
Vercel подхватывает изменения автоматически.

## Структура проекта

```
index.html, about.html, contact.html   — страницы сайта
style.css, script.js, data.js, i18n.js — стили и логика витрины
assets/                                 — логотип

data/products.json                      — товары каталога
data/slides.json                        — hero-слайды на главной
data/i18n.json                          — все тексты сайта (EN/RU)
data/filters.json                       — списки брендов/размеров/стран для фильтров

admin/index.html, admin.css, admin.js   — сама админ-панель (/admin)

api/order.js                            — заявка из корзины → Telegram
api/admin/login.js                      — вход в админку
api/admin/logout.js                     — выход
api/admin/session.js                    — проверка, залогинен ли
api/admin/data.js                       — отдаёт текущие данные из GitHub
api/admin/save.js                       — коммитит изменения в GitHub

lib/auth.js                             — проверка пароля + подпись сессии
lib/github.js                           — чтение/запись файлов через GitHub API

package.json                            — нужен, чтобы Vercel опознал проект
.env.example                            — какие переменные окружения нужны
```

## Как работает админка (без базы данных)

1. Заходишь на `твой-сайт.vercel.app/admin`, вводишь пароль.
2. Правишь товары / слайды / тексты — жмёшь «Сохранить».
3. Админка через серверную функцию делает **настоящий git-коммит** в этот
   репозиторий (обновляет соответствующий файл в `data/`).
4. Vercel видит новый коммит и автоматически передеплоивает сайт —
   изменения появляются на сайте примерно через 30–60 секунд.

Плюс такого подхода: не нужна отдельная база данных, а вся история правок
хранится в git — при желании можно откатить любое изменение.

## Настройка Telegram-бота (для заявок из корзины)

1. Открой в Telegram чат с **@BotFather**.
2. Отправь `/newbot`, придумай имя и username для бота (username должен
   заканчиваться на `bot`, например `mesir_orders_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — это и есть `TELEGRAM_BOT_TOKEN`.
4. Напиши **своему новому боту** любое сообщение (например «привет») —
   это обязательно, иначе бот не сможет писать тебе первым.
5. Узнай свой **chat_id**: открой в Telegram чат с **@userinfobot** и
   отправь ему `/start`. Он пришлёт твой числовой ID — это `TELEGRAM_CHAT_ID`.

## Настройка админ-панели

### 1. GitHub Personal Access Token

Нужен, чтобы серверная функция могла коммитить изменения от твоего имени.

1. GitHub → фото профиля → **Settings** → в самом низу слева
   **Developer settings** → **Personal access tokens** → **Fine-grained tokens**
   → **Generate new token**.
2. **Repository access** → **Only select repositories** → выбери именно
   этот репозиторий (не давай доступ ко всем репозиториям сразу).
3. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
   Больше никаких прав не нужно.
4. Создай токен, скопируй значение (вида `github_pat_...`) — это и есть
   `GITHUB_TOKEN`. Он показывается только один раз.

### 2. Остальные переменные

- `GITHUB_REPO` — `владелец/название-репозитория`, например `nazim/mesir-perfume-site`
- `GITHUB_BRANCH` — ветка, из которой деплоится сайт (обычно `main` или `master`)
- `ADMIN_PASSWORD` — придумай сам, это пароль входа в `/admin`
- `ADMIN_SESSION_SECRET` — любая длинная случайная строка. Можно сгенерировать
  в терминале: `openssl rand -hex 32`

## Деплой на Vercel

1. Залей проект в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com) → **New Project** → выбери репозиторий.
3. Framework Preset — оставь **Other** (это не Next.js/React, просто статика +
   serverless-функции, Vercel поймёт сам).
4. **До первого деплоя** зайди в **Project → Settings → Environment Variables**
   и добавь все переменные из `.env.example`:
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — для заявок
   - `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `GITHUB_TOKEN`, `GITHUB_REPO`,
     `GITHUB_BRANCH` — для админки
5. Нажми Deploy.
6. Проверь заявки: добавь товар в корзину → «Отправить заявку» → заполни
   форму → должно прийти сообщение в Telegram.
7. Проверь админку: открой `/admin`, введи `ADMIN_PASSWORD`, попробуй
   добавить тестовый товар — через ~30–60 секунд после сохранения он должен
   появиться на сайте.

**Если после смены переменных окружения ничего не меняется** — Vercel не
подхватывает новые env vars для уже существующих деплоев автоматически.
Deployments → три точки у последнего деплоя → **Redeploy**.

## Важно про бесплатный план Vercel

Hobby (бесплатный) план Vercel по их правилам предназначен только для
некоммерческого использования. Если сайт будет реально принимать заказы —
формально это уже коммерческое использование, и по правилам Vercel нужен
план **Pro** ($20/мес). Технически на Hobby всё будет работать без
ограничений — это вопрос соблюдения условий использования, а не
работоспособности кода.
